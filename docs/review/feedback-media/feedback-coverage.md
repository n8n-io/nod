## Follow-up feedback

- **Match Otto:** Geist and the existing app themes and tones throughout; no replacement typefaces or invented pinks.
- **Message actions:** the prototype uses hover caret/reaction controls and in-bubble timestamps; menus are scoped to the bubble and dismiss on an outside click. Quick reactions stay beside the trigger and More opens the full picker.
- **Files:** Inline files is selected. Draft and sent files share the native viewer and controls, with upload state on each composer item.
- **Navigation:** command palette and search dropped. Only desktop shortcut hints are proposed; web browser/system shortcuts are preserved.
- **Settings and missing pages:** deferred; the existing controls, Memory and useful empty states remain.
- **Connections:** compact cards sit inside their message, MCP server details remain visible, and Telegram has one Open action.
- **Sign-in:** Beside the chat is selected. Branded standalone pages remain for Telegram. The method-change action is above the form and redundant storage copy is removed from the proposal.
- **Onboarding:** Send stays right. The prototype offers completed action treatments in the existing theme; native OS preference acceptance is not claimed by these fixtures.
- **Feedback discovery:** the approved Brand invitation is implemented, without a CTA. It welcomes problems, positive feedback and ideas and says every message is read.
- **Secure actions:** compact Sign in securely and Confirm payment treatments remain in the local review; their new presentation is not installed in this branch.

## Additional bugs found while reviewing

- **ChatGPT connection:** the inspection runtime had a malformed Vault encryption key. With that key, OAuth could complete and then fail when saving the account, returning the generic sign-in error. The runtime key was repaired only after verifying there was no encrypted data. The product now checks credential storage before OAuth, API-key or endpoint connections begin and reports unavailable storage without exposing the underlying error. [Synthetic HTTP/database evidence](model-storage-regression.json) verifies no provider call or saved connection on failure and successful encrypted persistence after correction.
- **Credential status consistency:** form and polling responses now share one status mapper and both scope the operation lookup to its owner. The regression preserves the previous disagreement for a foreign-owned operation and verifies it is expired in both responses after the fix.
- **Review evidence:** current browser source was recaptured, raw PDF images are included with their hashes, and completed-action evidence distinguishes equal fixture state from the changed status-only API route.

## Acceptance limits

The local gallery is a design review, not a product deployment. Desktop screenshots use a renderer bridge fixture. Required Linux integration checks are reported separately from native macOS checks and any live sign-in attempt in the PR description. Native notification permission acceptance, installed-app onboarding and authenticated Instinct comparison are not claimed. Human UI acceptance remains required before merge.
