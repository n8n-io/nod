## Identity and default review

Read-only inspection of the recorded candidate found desktop selects the managed proxy regardless of saved project keys, and desktop settings pass only the vault key into the runtime. Non-desktop servers select direct Composio when `COMPOSIO_API_KEY` is explicitly configured; otherwise they select the proxy. Managed requests use an installation-derived Composio owner, never a caller-supplied legacy owner. Hosted installation keys use a domain-separated derivation from the tenant vault secret and owner; desktop/local keys persist in restricted local files.

No additional isolation blocker was found in those paths. This review does not establish seamless legacy upgrade behavior. Existing grants under legacy user IDs require the newly accepted reconnect flow; the separate app evaluation owns connection replacement and UI acceptance.
