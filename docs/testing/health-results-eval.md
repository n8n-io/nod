## Run, score and repair

1. Preflight the isolated app with one small read-only fixture task. Confirm account discovery, attachment bytes and receiving view independently. A broken fixture or service is an environment error, not an agent failure.
2. Freeze the case manifest and independent key. For HR-02, establish the inbox baseline first and then add one genuinely new fixture message; an old message already present at baseline does not test proactive discovery.
3. Use normal chat, source event handling, app tools, browser, workspace and scheduler. Never replace the agent's missing behavior with an evaluator's manual action. No ordinary regression test may call a live model, real connected account or real recipient.
4. Save observable output, task/turn/message IDs, complete synthetic tool trace, source snapshots, generated file hashes, schedule/run IDs, times and measured or unavailable cost. Score every required applicable check with its evidence path. Real-account acceptance has a separate private run record and cannot be inferred from fixture results.
5. Before changing code, record the failed check, general-cause hypothesis, predicted trace and evidence that would disprove it. Classify the red as agent gap, fixture fault, source change or evaluator fault.
6. Fix only a demonstrated general failure in its owning module. Repeat the frozen case, an independent holdout and the relevant regression suite. Keep original red evidence. Do not add CUF domains, health keywords, lab thresholds, fixture values, expected questions or medical decisions to runtime routing.
7. Run focused regression checks while editing, then repository validation. A green unit/integration test proves its boundary; an agent case remains red or not run until its own required outcome checks pass.

A candidate general improvement is justified only by a failed case: for example, missing attachment inspection belongs to document/tool guidance or download handling; ignoring a known appointment belongs to context reuse; inventing a date belongs to grounded planning; missing a promised reminder belongs to durable task continuation. Keep clinical interpretation in evidence-backed agent reasoning. Do not build a health-specific planner or diagnosis rules to satisfy the fixture.
