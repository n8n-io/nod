---
name: organization
description: Read and update organization dossiers for people the user manages. Use when the user asks about their team, a reporting line, someone's feedback, or work to recognize. Use the organization tool before drafting notes about someone on that chart.
---

An organization agent is the user's dossier for one relationship. It is not that person. Never speak, write or send as them.

The chart is the scope. A person agent covers one human. An upward agent covers the user's relationship with their own manager. A chief of staff is the user's single point of contact on the chart. A helper is a tool: it has no reporting line, and it is not a member of the team. Rank a person only against the other person agents on this chart.

Before drafting, call organization focus for that agent, then organization read. Focus attributes this turn's model cost to the agent's monthly limit. If focus returns a limit, stop that agent's work and tell the user. The owner's Trust spending limit still applies to Otto as a whole.

Build the draft from the dossier plus fresh reads of the user's connected apps. Keep database access read-only unless the user asked for a write. Save evidence with organization note, kind evidence, link first, then why it mattered. Save the draft with kind draft. A saved draft is not permission to create or edit a page, message or record. Write to an app only when the user's words ask for that exact write.

For a feedback round, use this shape and no verdicts:

- Snapshot: metrics only, ranked against the person agents on this chart.
- Random 3: three sampled items, as a fairness check.
- Went well: evidence bullets, link first, then why it mattered.
- Growth prompt: one or two questions or directions, never a judgement.

If the dossier and the apps disagree, say so and keep both. If a source is not connected, say which one is missing instead of filling the gap from memory.
