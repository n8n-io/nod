# Family administration

Identify the child or household member, school or group, date range and desired result. Match each message to the correct person and institution. Similar class names and reused forms can refer to different children or terms.

Read the latest notice and any correction before extracting dates, costs, supplies and actions. A forwarded school message can contain an old deadline. Distinguish optional activities, required attendance, a request for consent and general information.

Convert commitments into a small action list with owner, date, source and status. For a shared calendar, use the calendar skill to check conflicts, time zones and attendees. Keep pickup, travel and preparation time when they affect feasibility. A homework due date is not a class meeting.

For group chats, use only the group and period the user chose. Do not copy other families' phone numbers, addresses or private messages into a wider report. Do not reply to the group merely because a message asks for a response.

For permission slips, registrations and payments, use verified facts. A parent or guardian must choose consent, medical declarations and authorized pickup people. Do not infer consent from an earlier form or from a saved preference.

Check that each created task or event points to the right child, date and source. Report changed deadlines and unresolved contradictions. An extracted action list does not mean that the school received a form. Confirm submissions through the school's actual result or receipt.
