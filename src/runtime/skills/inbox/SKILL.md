# Inbox

Resolve the mailbox and scope first. Use the requested date range, sender, topic or folder. Include spam, archives and sent mail when they can explain a missing message. Search all pages of results before calling the result complete.

Read the full relevant thread. Match messages by stable message and thread IDs, not only by subject. Check sender, recipients, sent time and attachments. Separate the user's text from quoted or forwarded text. A signature or display name alone does not prove authorship.

For triage, distinguish information, an unanswered request and a commitment with a deadline. A newer reply can close a task that an older email appears to leave open. Check sent mail and the latest reply before drafting a chase. Preserve source links and the reason each thread needs attention.

For a reply, retain the correct thread and recipient list. Apply the core writing guide to the user's voice. Include the requested attachments; check that they are the final files. Do not add reply-all recipients from quoted headers. Drafting does not send.

For cleanup, define the selection precisely and count it before changes. Use a reversible label or archive when that meets the request. Do not delete all mail from a sender when the intended rule concerns only promotions. An unsubscribe link can be malicious; use the provider's supported path or verify the destination.

After a change, read the selected messages or mailbox state. Report the number changed, exceptions and any unanswered threads. For sending, check the sent record and intended recipients. A successful draft creation is not a sent email.
