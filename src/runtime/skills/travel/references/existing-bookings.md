# Existing bookings

Read the current booking before a change. Identify the seller of record, carrier, ticket status and each affected leg. A round trip can share one ticket; canceling one part can affect the rest. Do not cancel to inspect the price of cancellation.

Get the refund, credit, fee and remaining itinerary before the action. Check whether credits have expiry, name restrictions or limits on use. A replacement proposal does not authorize canceling the original. If a change completed but its result is unclear, read the booking again; do not submit it again.

For check-in, use the carrier's current window and the booked passenger details. Do not answer declarations from a guess. A seat choice can add a fee. Report whether check-in is complete and whether the boarding pass is available.

For a delay or baggage claim, preserve the flight, dates, notice, receipts and actual disruption. Check current carrier and official country rules. Explain the proposed remedy without promising compensation. A submitted claim needs a reference and a separate payment status.
